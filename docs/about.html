SceneWeaver turns a short English description into a playable micro-world. It deliberately combines local semantic AI with a bounded, auditable scene compiler.

The pipeline

  1. Understand: the pretrained all-MiniLM-L6-v2 sentence transformer runs locally through Transformers.js and ONNX Runtime. Normalized sentence embeddings are compared with seven world-theme descriptions and three mechanic descriptions.
  2. Compile: explicit text parsing extracts supported object counts, colors and timers. A safe compiler constructs a JSON scene plan and event-condition-action rules.
  3. Render: Three.js builds procedural 3D geometry. A Canvas2D perspective renderer uses the same scene graph if WebGL is unavailable.
  4. Play: collect crystals or activate switches, unlock the gate and finish. Inspect the rule list and use the accessible object controls.

What this does not do

It is not an LLM and does not generate arbitrary code, custom 3D meshes, full games or physics. It supports seven themes and three mechanics. Unrelated prompts map to a supported world rather than being followed literally. Similarity scores are not calibrated probabilities. Model inputs may be truncated at the model's token limit. The first model download needs internet access.

Privacy and cost

No API key, visitor account, paid inference or server is needed. Your prompt is processed in this browser. Model, code and font downloads contact Hugging Face, jsDelivr and Google Fonts, which receive ordinary request metadata. This app has no analytics or remote prompt endpoint.
